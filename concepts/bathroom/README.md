# Bathroom style proposals

Two AI-generated art-direction concepts for user review, made with the built-in imagegen tool. These are proposals for palette, shape, and material language; they are not game screenshots or final assets.

User preference received: **A's calmer colours**. Production should retain that palette with simplified chunky geometry and selective rounded edges. The user noted B's easier low-poly appearance; neither concept's detailed surfaces prescribe polygon or texture budgets.

The production baseline is now `warm_ceramic_v1`; see `../../docs/style-guide.md` and `../../materials/warm_ceramic_v1/palette.json` for exact authored colours and material recipes. Use those definitions for future models.

- A — Warm ceramic: cream, mint, peach, ochre, dark teal; rounded forms and soft morning light.
- B — Graphic comedy: lavender, cobalt, buttery yellow, coral, navy; faceted forms and stronger colour contrast.

Both target simple low-poly shapes and mostly opaque materials. Mirror space stays clear; visible props are toothbrush, toothpaste, cup, soap, towel, faucet, sink, and tub. No new character design is proposed.

Exact generation prompts are saved alongside the images. A's calm direction is selected. The Godot implementation must satisfy `../../docs/toothbrush_brief.md`; concept-image geometry is not a technical specification.
